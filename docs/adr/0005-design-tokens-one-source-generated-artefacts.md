# ADR 0005 — Design tokens: one source, generated artefacts, no hand-edited hex anywhere

- **Status:** Accepted, 2026-08-21
- **Deciders:** S. Le Boulanger
- **Related:** ADR 0001 (`kit`), ADR 0006 (typography)

## Context

The palette exists in several hand-maintained copies and they have already disagreed in a way that reached the artefacts.

- **86 hand-maintained colour literals in two files.** `slidegen/beamerthemeboulingua.sty:14-47` and `sheetgen/boulingua-sheet.sty:32-65` each carry **43 `\definecolor` invocations**: 2 brand defaults, **34 accent declarations** (`acc-<code>` and `acch-<code>` on 17 lines) and 7 foreground/rule/surface/CEFR colours. Seventeen codes for eighteen languages — **`pfa` is missing from both**. `pagegen/data/accents.yaml` already carries all 18 rows including `pfa #B5892B`/`#8C6A21`. The data was never wrong; the two hand-copied blocks were.
- **Two CSS token namespaces.** `pagegen/assets/css/custom.css` declares 9 `--boulingua-*` tokens and 13 `--network-*` tokens used 132 times, the second set introduced by the materials-network work and never reconciled. `--network-surface`, `--network-border`, `--network-fg-mute` and `--network-rail-bg` are the same roles as `surface`, `border`, `fg-muted` and a panel background.
- **The topic palette lives in three places** and agrees by hand: `daf/data/topics.yml`, `custom.css:614-620` (light) and `:631-637` (dark).
- **Hard-coded colour reaches the renderer.** `daf/assets/js/network/main.js:28` falls back to the literal `'#888'` for an unknown topic — a grey outside the token system entirely.
- **The public colour page is hand-written.** `website/content/design.md` carries a hand-maintained HTML table of 18 `<tr>` — one header and 17 language rows, `pfa` missing — which would need editing fifteen more times as the remaining courses arrive.
- **A course accent bleeds into a shared rule.** `custom.css:263-265` styles `.callout` with `border-left: 4px solid var(--boulingua-accent)` over `background: rgba(26, 115, 232, 0.06)` — hub blue on *every* course, so `daf` renders a teal bar on a blue wash.
- **Type is ad hoc.** 17 distinct font-size values across 41 declarations; four letter-spacings; 20 ad-hoc spacing values; a stray `3px` radius among `8px`, `4px`, `999px`, `6px` and `50%`.

## Decision

**`kit/design/tokens.yaml` is the only hand-edited token file in the org.** `build_tokens.py` emits deterministically — sorted keys, `\n` line endings, no timestamps — into every consumer:

| Generated artefact | Consumer |
|---|---|
| `kit/assets/css/tokens.css` | loaded before `custom.css` |
| `kit/latex/boulingua-tokens.sty` | `\RequirePackage`d by both `.sty` files |
| `kit/data/accents.yaml` | `head/extensions.html`, `make_icon.py` |
| `kit/design/tokens.json` | Python generators and gates |
| `website/content/design.md` | the public colour page — generated, never hand-written |

Four mechanisms make drift impossible rather than merely detectable. The decision is not done until all four hold.

1. **The second source is deleted, not policed.** The two `\definecolor` blocks are removed and replaced by `\RequirePackage{boulingua-tokens}`.
2. **Every generated file carries a provenance header** — `% GENERATED by build_tokens.py from tokens.yaml@<sha256>. Do not edit.` — is listed in `kit/RELEASE/SHA256SUMS` and is marked `linguist-generated` in `.gitattributes`, so a hand edit is visible in review before it is caught in CI.
3. **`build_tokens.py --check` regenerates into a temporary tree and diffs**, failing the build with the path and the differing line.
4. **The raw material is forbidden.** Zero literal `#rrggbb`, `rgb(`, `rgba(` or `hsl(` outside `tokens.css` in `assets/css/*.css`; zero `\definecolor` outside `boulingua-tokens.sty` in `latex/*.sty`. After this decision there is **exactly one file in the org where a colour may be written by hand**, and the gate proves it on every push.

The token set is fixed at the same time: one `--boulingua-*` namespace, with `--network-*` retained as an alias block for one release so the 132 call sites migrate by tool rather than by hand, then deleted. `cefr.b` becomes an explicit **alias** of `brand.hub` rather than a second literal that happens to agree. `rule` becomes opaque on both sides — today `custom.css:10` sets `rgba(0, 0, 0, 0.12)`, which composites unpredictably over callout washes. `surface` unifies to LaTeX's cool `#F7F8FA`, not web's warm `#FAFAF7`, because cool grey reads neutral under the warm accents `pfl #AD701F`, `pfa #B5892B` and `jfl #867B18`. Type collapses to a 1.125 modular scale of eight steps anchored at `1rem`; letter-spacing to two values; spacing to a 0.25 rem ramp; radius to `sm 4px = 3pt`, `md`, `lg`, `pill`, `circle`; elevation to two levels, and **print never emulates a shadow** — depth on paper is rule weight.

The `.callout` rule becomes accent-correct and degrades safely:

```css
.callout { background: rgba(0, 0, 0, 0.04);
           background: color-mix(in srgb, var(--boulingua-note) 7%, transparent); }
```

The flat fallback is emitted first and deliberately: a classroom machine that does not understand `color-mix()` must get a neutral wash, not an unstyled callout.

## Consequences

- Adding language nineteen is one edit to `tokens.yaml`, not nineteen. The public colour page renders the new row without a commit to `website`.
- Web and print cannot disagree about a colour, because both read the same generated file.
- `pfa`'s missing accent is fixed by construction, and the class of defect that hid it cannot recur.
- **Cost:** roughly 40 CSS declarations shift by ≤1 px when the ad-hoc sizes snap to the scale. No URL changes and no revenue exposure — the VG Wort *Mindestumfang* counts characters, not pixels.
- **Cost:** 132 `--network-*` call sites carry an alias shim for one release. The alias block is dated in `tokens.yaml` and deleted on schedule, not when someone remembers.
- **Cost:** generated files are committed, so every token change produces a diff across several artefacts. That is the visible half of the mechanism, not an accident of it.

## Alternatives considered

**Keep the parallel palettes and add a comparison gate.** Rejected. A gate that compares two hand-maintained sources reports the disagreement but cannot say which side is right, and it is exactly what would have flagged `pfa` for a year without fixing it. Deleting the second source removes the question.

**Make the CSS custom properties the single source and derive LaTeX from them.** Rejected. Parsing CSS to produce `\definecolor` puts a fragile reader between the source and the print path, and the source would still be a file that invites hand-editing. A neutral YAML source treats both consumers as outputs.

**Rename the token prefix `--boulingua-` to `--blg-`.** Rejected. It touches roughly 150 declarations for zero user-visible gain.

**Hand-write `website/content/design.md` but check it in CI.** Rejected for the same reason as the palettes: the check can only report that the page and the data differ, and the page is public, so a stale row is a published error.
